# Independent Cryptomator interoperability tests

These optional tests compile a small, ordinary Java program against the unmodified
libraries from an installed Cryptomator desktop app. There is no JNI bridge,
hand-generated bytecode, mounting, or Java dependency in the Starcrypt executable.

Requirements for the verified Cryptomator 1.19.6 library set:

- A **full JDK 26**, including `java` and `javac`. The desktop app's trimmed runtime
  alone is insufficient. Preview-class compatibility requires the matching major
  JDK version; the launcher deliberately rejects other compiler versions.
- Cryptomator at `/Applications/Cryptomator.app`, or `--cryptomator-app PATH`.
- Python 3 and Rust with the locked dependencies available locally.

Set `JAVA_HOME` to the full JDK installation and run from the project root:

```sh
python3 tests/interop/run.py
```

Alternatively:

```sh
python3 tests/interop/run.py --jdk-home /path/to/jdk/Contents/Home
```

The launcher validates its dependencies before creating any fixtures. It compiles
`StarcryptOracle.java`, records official-library hashes, generates new GCM/CTRMAC
vaults with disposable passwords, runs the Rust public-API tests, and asks the
official implementation to read Starcrypt output. It also runs the ordinary Rust
suite (including ZIP and 7z round trips) and a locked release build.
Independent archive-reader checks and the complete release checklist are in
[docs/releasing.md](../../docs/releasing.md#checks).

All generated data goes into a fresh, ignored folder under `verification-results/`.
Use `--output NEW_PATH` to choose another new directory. Never use production vaults
or real passwords as fixtures. Logs and JSON reports are retained for inspection.

Files:

- `StarcryptOracle.java`: official-library vault creation and complete byte/link comparisons.
- `fixtures.py`: deterministic boundary-size, Unicode, long-name, and symlink fixtures.
- `run.py`: JDK preflight, compilation, execution, and reports.
- `compare.py`: optional manual desktop/WebDAV fixture, snapshot, and comparison tool.

The normal Rust tests need neither a JDK nor Cryptomator:

```sh
cargo test --locked
```
